# CN Surprise Test – Cisco Packet Tracer Practicals

This repository contains my Computer Networks practical work using **Cisco Packet Tracer**.

## Practicals

### Practical 15 – Configuring RIPv2 (Classless) Routing in Packet Tracer

This practical covers the configuration and verification of **RIPv2 (Routing Information Protocol version 2)**.

Topics covered:

- RIPv1 vs RIPv2
- Classless routing
- VLSM and subnetting
- Network topology
- IP addressing
- Router configuration
- RIPv2 configuration
- `no auto-summary`
- Routing table verification
- Connectivity testing using `ping`

📄 **[View Practical 15](Practical_15.md)**

### Practical 16 – Configuring BGP Routing in Packet Tracer

This practical covers the configuration and verification of **BGP (Border Gateway Protocol)** using two Autonomous Systems.

Topics covered:

- BGP fundamentals
- eBGP and iBGP
- Autonomous Systems
- Two-AS network topology
- IP addressing
- Serial eBGP peering
- BGP neighbor configuration
- Network advertisement
- BGP table verification
- Routing table verification
- Connectivity testing using `ping`
